# DL836 Research & Analytics CA1

This repository contains my work for the **Research & Analytics CA1** assignment.

The repository contains the completed Jupyter notebooks for **Task 1** and **Task 2**, along with the datasets used for the analysis.

## Tasks

### Task 1 – Retail Performance Analytics

**Notebook:** `notebooks/01_retail_performance.ipynb`

This notebook contains the analysis and predictive modelling for the retail performance dataset, including:

- Data preparation and quality assessment
- Exploratory data analysis
- Pivot tables and correlation analysis
- Predictive analytics
- Feature importance
- Data visualisations

**Dataset:** `data/retail/`

---

### Task 2 – Recommendation System Development

**Notebook:** `notebooks/02_recommendation_system.ipynb`

This notebook contains the development and evaluation of recommendation systems using customer, product and transaction data, including:

- Data preparation and integration
- Customer analytics
- Product analytics
- GroupBy and pivot table analysis
- Popularity-based recommendations
- Collaborative filtering
- Recommendation evaluation and comparison

**Dataset:** `data/recommendation/`
